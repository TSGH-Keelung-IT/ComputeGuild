## 系統需求

- Windows 10／11（64 位元）。
- 已安裝並登入 Codex 桌面程式。

## 安裝

1. 下載 **ComputeGuild-Setup-x64.exe**。
2. 若舊版程式正在執行，請先關閉。
3. 雙擊安裝檔，依畫面完成安裝。
4. 開啟 Codex，再雙擊桌面「Codex 冒險者公會」。

不需另外安裝 .NET 或使用量儀表板。
